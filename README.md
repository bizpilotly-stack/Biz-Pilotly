# BizPilotly

> **Calculate. Create. Manage.**

BizPilotly is a modern, lightweight business operating platform designed specifically for freelancers, independent consultants, and small service businesses. It brings together financial calculations, professional document generation, and core business management tools into a single, cohesive workflow.

---

## ✨ Features

### 1. 🔢 8 Specialized Business Calculators
- **Profit Calculator**: Compute gross & net profit with direct costs, overheads, and taxes.
- **Profit Margin Calculator**: Determine optimal selling prices based on target margin percentages.
- **Markup Calculator**: Calculate cost markups for service packages.
- **ROI Calculator**: Measure financial returns on equipment, software, or campaign investments.
- **Break-Even Calculator**: Identify units or billable hours needed to cover fixed overheads.
- **Discount Calculator**: Apply flat or percentage discounts while tracking net margins.
- **Commission Calculator**: Compute referral fees, broker cuts, and tiered partner payouts.
- **Percentage Calculator**: Versatile calculations for changes, fractions, and shares.

### 2. 📄 4 Live Document Generators
- **Invoice Generator**: Split-screen editor with dynamic line items, automatic tax/discount calculations, and client details.
- **Quote / Estimate Generator**: Professional quotations with validity dates and terms.
- **Receipt Creator**: Proof of payment and settlement receipts.
- **Proposal Builder**: Structured scope of work and deliverables pitching.
- *Real-time printable document preview with `@media print` PDF-ready stylesheets.*

### 3. 📊 Business Operations Dashboard
- **Overview**: Real-time KPI summaries, recent invoices, recent payments, and activity timeline.
- **Clients**: Centralized client directory with search, filtering, and financial summaries.
- **Documents Ledger**: Filter documents by type and status (`Draft`, `Sent`, `Viewed`, `Accepted`, `Paid`, `Overdue`, `Cancelled`).
- **Payments**: Track received funds, pending wire transfers, and overdue invoices.
- **Expenses**: Categorized expense tracking (Software, Marketing, Transport, Equipment, Contractors, Utilities, Other).
- **Profit & Performance**: Revenue vs. Expense monthly trend charts and profit margin analytics.
- **Settings**: Business entity details, default currency, tax rates, and document numbering prefixes.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/bizpilotly-stack/Biz-Pilotly.git

# Navigate to the project directory
cd Biz-Pilotly

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will be accessible at `http://localhost:3000/`.

### Build for Production
```bash
npm run build
```
